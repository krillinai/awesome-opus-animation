> 正在收录中。欢迎提供 X 原帖链接；优先收录作者本人发布、明确说明所用模型的作品。

按分类浏览作品；点击封面观看视频，点击作品名称查看制作说明与提示词。

### Claude 的一生

- **作者**：[@shfred0](https://x.com/shfred0)

> I will only give you two words that MUST be included in the title, everything else is your choice.

- 每个分类下先放视频预览表格，每行三项；同类作品的竖屏封面集中排列。不足三项的行留空，后续新增案例可补入空位。
- 预览使用原帖的视频封面，点击封面跳转作者原帖；点击作品名称跳转详情。详情记录样片、制作说明和有出处的提示词，不重复插入封面。
